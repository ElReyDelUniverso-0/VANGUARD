## Cómo encenderla en tu casa (gratis, para siempre)

Con Node.js (gratis):

```
git clone https://github.com/ElReyDelUniverso-0/VANGUARD.git
cd VANGUARD
npm install
npm run dev:real
```

Abre http://localhost:3000 — la casa despierta en tu propia máquina, sin pagarle a nadie. (Con Bun, que es el gestor de la casa: `bun install && bun run dev`.)

## Cómo seguir construyéndola con otra IA

Dile a cualquier IA, de la herramienta que sea:

> «Lee AGENTS.md, worklog.md y src/lib/regla-oro.ts ANTES de tocar nada.»

Esos tres archivos son el alma de Vanguard: el contrato de trabajo, la memoria completa de 439 versiones y las leyes de la casa. Cualquier IA que los lea es heredera legítima. Por eso documentamos TODO desde el día uno: para que ninguna despedida pudiera ser fatal.
